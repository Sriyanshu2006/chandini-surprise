# Cute Surprise Website 💗

A mobile-first interactive website inspired by the uploaded reference video.

## Run it

Open `index.html` in a browser.

For the best development experience, use VS Code + the Live Server extension.

## Customize first

Open `index.html` and change:
- `Ayushi` to the person's name
- The section headings
- Memory captions

Open `script.js` and edit the `note` variable for your personal message.

## Add real photos

Put your images in:

`assets/photos/`

Then replace a `.photo-placeholder` div with:

```html
<img src="assets/photos/photo1.jpg" alt="Memory">
```

The next step is to match the reference video more closely with the exact photos, GIFs, fonts, transitions, and section layouts.
